과제명
PyQt와 MySQL을 활용한 GUI 재고 관리 프로그램 개발

주제
어떤 품목이든 추가 및 삭제가 가능한 재고관리 프로그램을 기획 및 구현

필수사항
회원가입 및 로그인 기능 
데이터 목록 보여주기 기능 
데이터 직접 입력해서 추가하기 기능 
데이터 삭제 기능 
데이터 수정 기능 

상세항목
이미 등록된 점포 리스트는 로그인 시 콤보박스로 구성하여 선택 가능하도록
일련번호를 등록할 수 있는가. 
상품명을 등록할 수 있는가. 
가격을 등록할 수 있는가. 
등록된 내용을 수정할 수 있는가. 
사용자가 한눈ㄱ에 파악할 수 있는 UI로 구성이 되어있는가. 
재고 관리가 쉬운가.
    - 유통기한 및 소비기한이 있는 품목은 별도로 관리되는가. 
    - 동일 품목이더라도 입고일에 따른 관리가 이루어지는가. 
    - 부족한 재고는 표시가 되는가. 
    - 부족한 재고를 발주할 수 있는 시스템이 마련되어 있는가.

시나리오
로컬 위치에 데이터베이스 생성 ('invetorydb') 
데이터 베이스에 테이블 구성 ('이름', '가격', '수량' 등) 
어떤 모듈별로 구성해야하는가.
    -main.py (위젯, 테이블 등 구성 파일) 
    -app.py (실행파일) 
    -login_dialog.py 
    -등등 
우선 등록 및 수정이 가능한 내용부터 진행하며, 기능을 하나씩 추가 구현하며 진행 
구현 순서
    등록 -> 수정 -> 삭제 -> NULL처리 (판매 불가 등) 

동작절차(구상)
1. 점포 선택이 가능한 콤보박스 생성
2. 점포 선택 후 ID와 PW를 입력할 수 있는 창 하단에 생성
    2.1. ID와 PW가 없는 경우 회원가입 
    2.2. ID와 PW가 틀린경우 '아이디와 비밀번호를 다시 입력해주세요.' 출력 및 입력이 정확한 경우 로그인 
3. 로그인된 점포에 따라 해당 점포의 재고가 도출되어야 한다.
